# 机器人产业链交互学习网站

面向初学者的中文交互图谱。从仓储搬运等真实应用出发，理解工业机械臂、移动机器人和人形机器人的整机、系统、软件及关键零部件。

## 本地启动与验收

建议使用 Node.js 22 LTS（本次验证为 22.22.0）及 npm 10。

```bash
npm ci
npm run dev -- --host 127.0.0.1
```

打开终端显示的本地地址（通常为 `http://127.0.0.1:5173`）。开发预览仅在本机监听，不需要发布或合并 PR。

如果默认 npm 缓存目录没有写入权限，可指定一个自己有权限的缓存，例如 `npm ci --cache ../npm-cache`；不必修改系统目录的权限。

```bash
npm test
npm run build
npm run preview -- --host 127.0.0.1
```

生产构建位于 `dist/`，预览端口通常为 4173。项目不依赖后端、登录、数据库或环境变量。不要用 `file://` 直接打开源码中的 `index.html`。

人工验收应覆盖节点打开/关闭、相关节点跳转、企业/产品搜索、产业环节与机器人类型组合筛选、空结果复位、地图缩放与复位、六步学习路径、键盘操作以及手机列表和详情面板。截图保存在仓库外，不加入 Git。

## 内容维护与事实核实

内容位于 `src/data/industry.ts`，组件不承载企业产品事实：

- `nodes`：15 个知识节点，包括通俗解释、作用、上下游、难点、指标、企业/开源项目产品与来源。
- `relations`：节点连线，本版仅有技术依赖，不表示已证实的企业间供货。
- `learningPath`：六步新手路径，区分定位/SLAM 与导航。
- `Source`：标题、URL、发布方、`checkedAt`（最近核查尝试）、`accessed`（成功读取并核实日期）、可选 `published`、`verification`、`evidence`（明确支持范围）及可选 `note`（限制或未能核实原因）。

2026-09-22 已逐条检查原有 15 个来源；修复旧链接、具体化产品案例并补充独立来源后，页面使用 26 个实际读过的一手来源。完整原链接结果、替换原因和证据见 [来源审核记录](docs/source-audit-2026-09-22.json)。旧链接访问失败的记录仍然保留，不能称这些原 URL 已核实。

“已核实”仅说明原始资料支持该条 `evidence` 中的陈述，不意味着独立测评产品性能，也不代表整个节点的所有技术概述均获验证，更不证明供应关系。网页按每条资料状态渲染企业卡、引用与汇总；未获得直接证据的条目须保持 `pending`，显示原因，不填写成功核实日期。

请先阅读 [AGENTS.md](AGENTS.md)。新增或修改内容时逐条打开原始链接，再运行测试和构建。网页计数依据实际使用的独立 URL 自动计算。

## 静态部署

- **GitHub Pages / GitLab Pages**：配置静态部署流程，发布 `npm run build` 生成的 `dist/`。Vite 使用相对资源路径。
- **Netlify / Vercel**：构建命令 `npm run build`，输出目录 `dist`。
- **其他静态服务器**：上传 `dist/` 内容即可。

这些只是部署说明；本次验收没有合并 PR 或部署网站。本站仅作学习导览，企业案例不构成采购或投资建议。
